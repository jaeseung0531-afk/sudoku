# SUDOKU

브라우저에서 바로 실행되는 스도쿠 게임입니다. HTML5 · CSS3 · Vanilla JavaScript만 사용하며 서버, 데이터베이스, 외부 라이브러리가 필요 없습니다.

```
sudoku/
├── index.html             화면 구조 (보드, 버튼, 모달)
├── style.css              디자인 (라이트/다크 테마, 반응형)
├── script.js              퍼즐 생성·풀이·검증, 게임 로직, 저장
├── manifest.webmanifest   앱 설치 정보 (이름, 아이콘, 전체화면)
├── sw.js                  오프라인 실행용 서비스 워커
├── icons/                 앱 아이콘 (192·512·maskable·Apple)
└── README.md
```

## 실행 방법

`index.html`을 더블클릭해 크롬·엣지·사파리·파이어폭스 등 브라우저로 열면 됩니다. 처음 실행하면 난이도 선택 창이 뜨고, 고르는 즉시 새 퍼즐이 만들어집니다.

## 휴대폰에 앱으로 설치 (PWA)

이 게임은 설치형 웹앱(PWA)입니다. 설치하면 홈 화면 아이콘으로 주소창 없이 전체화면 실행되고, **인터넷이 없어도** 플레이할 수 있습니다.

1. 폴더 전체를 **HTTPS** 주소로 올립니다 (예: GitHub Pages). 앱 설치와 오프라인 기능은 브라우저 보안 정책상 `https://`에서만 동작합니다.
2. 휴대폰에서 그 주소를 엽니다.
   - **안드로이드 (Chrome)**: 화면 상단의 **설치** 버튼을 누르거나, 메뉴(⋮) → **앱 설치**.
   - **아이폰 (Safari)**: 공유 버튼 → **홈 화면에 추가**.
3. 한 번 열면 앱 파일이 휴대폰에 저장되어 이후에는 오프라인에서도 실행됩니다.

파일을 수정해 다시 올릴 때는 `sw.js`의 `CACHE_VERSION`을 올려야(`sudoku-v2` 등) 설치된 앱에 새 버전이 반영됩니다.

PC에서도 같은 주소를 크롬/엣지로 열면 주소창 오른쪽 설치 아이콘으로 데스크톱 앱처럼 설치할 수 있습니다.

## 조작법

| 동작 | 마우스·터치 | 키보드 |
|---|---|---|
| 칸 선택 | 칸 클릭/탭 | 방향키 (가장자리에서 반대편으로 순환) |
| 숫자 입력 | 아래 숫자 버튼 1~9 | `1`~`9` |
| 숫자 삭제 | 지우기 | `Delete` / `Backspace` / `0` |
| 메모 모드 켜기/끄기 | 메모 | `M` |
| 힌트 | 힌트 | `H` |
| 새 게임 (난이도 선택) | 새 게임 / 상단 난이도 칩 | `N` |
| 되돌리기 | 되돌리기 | `U` |
| 선택 해제 · 창 닫기 | | `Esc` |

- 처음부터 주어진 숫자(진한 검정)와 힌트로 채운 숫자(초록)는 수정할 수 없습니다. 직접 입력한 숫자는 파란색입니다.
- 선택한 칸의 행·열·박스가 옅게 표시되고, 같은 숫자는 진하게 강조됩니다. 메모 안의 같은 숫자도 함께 강조됩니다.
- 숫자 버튼 아래 작은 숫자는 그 숫자를 앞으로 몇 개 더 놓아야 하는지입니다. 9개를 모두 맞게 놓으면 버튼이 흐려집니다.

### 오류 표시

- 정답과 다른 숫자를 넣으면 숫자가 빨간색으로 바뀌고 칸이 살짝 흔들리며, 상단 **실수** 횟수가 올라갑니다.
- 같은 행·열·박스에 같은 숫자가 있으면 충돌하는 칸 모두에 옅은 빨간 배경이 표시됩니다.
- 팝업이나 소리는 없으며 게임 진행을 막지 않습니다.

### 메모

메모 모드를 켜고 숫자를 누르면 칸 안에 작은 후보 숫자가 3×3 위치에 기록됩니다(같은 숫자를 다시 누르면 지워짐). 어느 칸에 정답 숫자를 넣으면 같은 행·열·박스 메모에서 그 숫자가 자동으로 지워집니다.

### 힌트

선택한 칸에 정답을 채웁니다. 칸을 선택하지 않았거나 이미 맞는 칸이면 아직 틀렸거나 빈 칸 중 하나를 골라 채웁니다. 사용 횟수는 상단과 완료 화면에 표시되고 통계·게임 기록에도 저장됩니다.

## 난이도

난이도는 빈칸 개수뿐 아니라 **풀이에 필요한 논리 기법**으로 정합니다. 퍼즐을 만든 뒤 내장된 논리 풀이기로 사람처럼 풀어 보고, 어떤 기법까지 필요했는지를 판정합니다.

| 난이도 | 주어진 숫자 | 필요한 기법 |
|---|---|---|
| 쉬움 | 37~38개 | 네이키드 싱글·히든 싱글만으로 풀림 |
| 보통 | 31~32개 | 포인팅·클레이밍(락드 캔디데이트)이 반드시 필요 |
| 어려움 | 26~29개 | 네이키드 페어·트리플, 히든 페어, X-윙 필요 |
| 매우 어려움 | 23~28개 | 위 기법만으로는 막혀 고급 기법이나 깊은 추론 필요 |

## 주요 기능

- 매 게임 새 퍼즐 무작위 생성 (해가 정확히 하나인 것만 사용)
- 4단계 난이도, 게임 시작 전 선택
- 숫자 버튼·키보드 입력, 방향키 이동, 되돌리기
- 메모(후보 숫자)와 자동 메모 정리
- 힌트와 사용 횟수 기록
- 오답·규칙 충돌 즉시 표시
- 타이머 (탭이 숨겨지거나 창이 열려 있으면 일시정지, 완료 시 정지)
- 완료 화면: 완성 시간, 힌트, 실수, 최고 기록, 다시 하기 / 같은 난이도로 새 게임 / 난이도 변경
- 새로고침·브라우저 재시작 후 진행 중인 게임 그대로 복구
- 난이도별 최고 기록, 통계(플레이 수, 완료 수, 승률, 평균 시간, 최고 기록, 힌트 수), 최근 완료 기록
- 다크 모드 (설정 유지, 처음 방문 시 시스템 설정 따름)
- PC·모바일 반응형, 엄지로 누르기 쉬운 숫자 버튼

## 퍼즐 생성 알고리즘

`script.js`의 생성·풀이·검증 함수는 서로 분리되어 있습니다.

1. **정답판 생성** — `generateSudoku()`: 빈 판을 백트래킹으로 채웁니다. 후보가 가장 적은 칸부터 채우고(MRV), 후보 숫자 순서를 섞어 매번 다른 정답판을 만듭니다. 행·열·박스 사용 여부는 비트마스크로 관리해 빠릅니다.
2. **숫자 제거** — `carvePuzzle()`: 정답판에서 중앙 대칭인 두 칸씩 무작위로 지우고, 목표 개수에 못 미치면 한 칸씩 더 지웁니다. 지울 때마다
   - `hasUniqueSolution()`으로 해가 하나인지 확인하고(두 번째 해를 찾으면 즉시 중단),
   - `ratePuzzle()`로 난이도 상한을 넘지 않는지 확인합니다.
   조건을 깨면 그 칸은 되돌립니다.
3. **난이도 맞추기** — `generatePuzzle()`: 완성된 퍼즐의 논리 난이도가 목표 범위면 채택하고, 아니면 다시 만듭니다. 시도 횟수(최대 1,500회)와 시간(2.5초)에 상한이 있어 **무한 루프가 생기지 않으며**, 상한에 닿으면 그때까지 가장 목표에 가까운 퍼즐을 씁니다.
4. **검증** — `validatePuzzle()` / `createVerifiedPuzzle()`: 최종 퍼즐을 다시 검사합니다.
   - 주어진 숫자끼리 규칙 위반이 없는지
   - 정답판이 완전하고 규칙에 맞는지, 주어진 숫자와 일치하는지
   - 해가 존재하고 정확히 하나인지, 그 해가 정답판과 같은지
   하나라도 실패하면 버리고 새로 만듭니다.

### 풀이 알고리즘

- `solveSudoku()` / `countSolutions()`: 비트마스크 + MRV 백트래킹. 유일성 검사에 사용합니다.
- `ratePuzzle()`: 사람이 쓰는 기법(싱글 → 락드 캔디데이트 → 페어·트리플·히든 페어 → X-윙)을 쉬운 순서대로 적용해 풀어 보고, 사용한 가장 어려운 기법 단계를 난이도로 돌려줍니다.

### 검증 결과 (개발 중 실행)

난이도별 300개씩 총 1,200개 퍼즐을 생성해 검사했습니다. 모든 퍼즐이 해가 정확히 하나였고, 모두 목표 난이도 범위 안이었습니다. 퍼즐 1개 생성 시간은 평균 0.3~31ms, 최대 171ms였습니다.

## 저장 방식

모든 데이터는 브라우저 `localStorage`에 저장되며 외부로 전송되지 않습니다.

| 키 | 내용 |
|---|---|
| `sudoku.v1.game` | 진행 중인 게임: 난이도, 퍼즐, 정답, 현재 입력, 메모(칸별 비트마스크), 힌트로 채운 칸, 선택된 칸, 경과 시간, 힌트·실수 횟수, 메모 모드, 되돌리기 기록, 완료 여부 |
| `sudoku.v1.stats` | 난이도별 플레이 수·완료 수·누적 시간·최고 기록·힌트 수, 최근 완료 기록 50개(날짜, 시간, 힌트, 실수) |
| `sudoku.v1.theme` | `light` 또는 `dark` |

- 입력할 때마다, 그리고 타이머가 1초 지날 때마다 게임을 저장합니다.
- 불러올 때 저장된 퍼즐을 다시 검증하고, 형식이 깨졌으면 무시하고 새 게임을 시작합니다.
- 기록을 지우려면 브라우저 개발자 도구에서 위 키를 삭제하면 됩니다.
